## 구현된 기능

- 지형: 노이즈 기반 바이옴 생성, 이능 편차 지역(마나 증폭/반발), 재해에 의한 영구·일시 지형 변형
- 세력: 인구 성장·영토 확장·최초 접촉, 절차 생성 문장(방패 SVG), 자원(식량/금속/마나)과 무역·기근
- 사상(Paradigm): 정치·종교·경제·이능·외교 5개 도메인, 도메인 간 영향 그래프, 전향, 소멸, 로스트 테크놀로지 → 유물
- 외교: 비대칭 우호도, 진심/표면 이원화(공동의 적 제약과 배신), 사소한 사건 무마/확대, 정략혼
- 전쟁: 원인/경과/전환점/결과 슬롯 조합 서술, 전쟁 명명(순번·원인·이명)
- 인물: 재능·성향·계급, 계급 변동, 혼인·출산·계승, 노화와 사망, 중요도별 기록 분량 차등
- 하위세력: 종파·정파의 충성도 표류, 반란(진압 또는 독립)
- 무소속: 위협 몬스터, 은둔 현자, 유물
- 문자 체계: 표음/표의/상형 문자를 절차 생성하여 이름을 실제로 표기
- 아카이브: 위키식 상호 링크, 리플레이, 세력별 흥망사 클립
